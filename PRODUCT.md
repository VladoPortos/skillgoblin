## Users and purpose

SkillGoblin serves small trusted-LAN households and homelab operators studying a local video course library. Learners need dependable playback and progress; administrators need recoverable data and understandable storage diagnostics.

## Design principles

Preserve the existing light/dark themes, indigo primary controls, system typography and familiar course layouts. New status and diagnostics surfaces should explain an actionable state without blocking study unnecessarily. Use plain language, visible keyboard focus, semantic labels, and polite live announcements. Reliability features must preserve history and show failures rather than imply success.
